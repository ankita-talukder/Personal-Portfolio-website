# 🌸 Personal Portfolio Website

Welcome to my personal portfolio website!
This website showcases my skills, projects, experience, and contact information as a **Web Developer**.

## ✨ About the Project

This portfolio is designed as a modern, responsive, and interactive single-page website. It includes smooth scrolling, animated sections, glassmorphism UI elements, and a contact form.

The goal of this project is to create a professional online presence where visitors can easily explore my work and connect with me.

## 🚀 Features

* 🏠 Responsive Home section
* 👩‍💻 About Me section
* 🛠️ Skills showcase
* 💻 Project showcase
* 📩 Contact section
* ✨ Scroll-based animations
* 🌈 Glassmorphism design
* 📱 Responsive design for mobile, tablet, and desktop
* 🔗 Social media and GitHub links
* 📄 Downloadable resume
* 📬 Contact form for sending messages
* 🎨 Custom pastel color theme

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, responsive design, animations, and glassmorphism
* **JavaScript** — Interactions, scroll animations, and form handling
* **Font Awesome** — Icons
* **Formspree** — Contact form submission

## 📱 Responsive Design

The portfolio is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

CSS media queries are used to adjust layouts, navigation, project cards, contact sections, and other components for different screen sizes.

## 📬 Contact Form

The contact form allows visitors to send a message directly through the portfolio.

The form uses **Formspree** to handle submissions without requiring a custom backend.

Before deployment, replace the Formspree URL in `index.html` with your own form endpoint.

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/ankita-talukder/Personal-Portfolio-website
```

### 2. Open the project

```bash
cd portfolio
```

### 3. Run the website

Open `index.html` in your browser.

For the best development experience, use the **Live Server** extension in VS Code.
